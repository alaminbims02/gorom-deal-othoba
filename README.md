# গরম ডিল — Headless WooCommerce (Next.js + WordPress)

ফ্রন্টএন্ডের **সব কিছু** (লোগো, টপবার, হিরো স্লাইড, প্রোমো, হোম সেকশনের ক্রম, ট্রাস্ট বার, ফুটার, ডেলিভারি চার্জ, জেলা, SEO, ট্র্যাকিং, UI-র লেখা ইত্যাদি) WordPress অ্যাডমিন থেকে নিয়ন্ত্রণযোগ্য।

```
Browser ──► Next.js (Vercel)  ──server-side──►  WordPress + WooCommerce + gorom-headless প্লাগিন
               │  /api/order, /api/track, /api/quote  ──proxy──►  /wp-json/gd/v1/*
               ◄── webhook: /api/revalidate  ◄── (পণ্য/সেটিংস সেভ করলে)
```

| ফোল্ডার | কী আছে |
|---|---|
| `frontend/` | Next.js 16 (App Router, TypeScript, Tailwind 4) |
| `wordpress-plugin/gorom-headless/` | কাস্টম WP প্লাগিন (সেটিংস পেজ, প্রোডাক্ট/ক্যাটাগরি মেটা, REST `gd/v1`, অর্ডার, ওয়েবহুক, সিড) |

> নিরাপত্তা: WooCommerce কী/সিক্রেট শুধু Next.js সার্ভারে (env) থাকে। ব্রাউজার কখনো এগুলো দেখে না; `NEXT_PUBLIC_` ব্যবহার করা হয়নি। দাম, ডেলিভারি চার্জ ও কুপন সবসময় WordPress সার্ভারে আবার হিসাব হয়।

---

## ১. WordPress ইনস্টল ও প্রস্তুতি

1. একটি হোস্টিংয়ে WordPress (৬.২+ , PHP ৭.৪+) ইনস্টল করুন। সাইটে **HTTPS** থাকতে হবে (Woo REST Basic Auth-এর জন্য বাধ্যতামূলক)।
2. **Settings → Permalinks** এ "Post name" সিলেক্ট করে সেভ করুন (`/wp-json` কাজ করার জন্য)।
3. প্লাগিন ইনস্টল ও অ্যাক্টিভ করুন:
   - **WooCommerce** (WordPress.org থেকে)
   - **Gorom Headless** — `wordpress-plugin/gorom-headless` ফোল্ডারটি জিপ করে (`gorom-headless.zip`) **Plugins → Add New → Upload** করুন, অথবা `wp-content/plugins/` এ কপি করুন।
4. WooCommerce সেটআপ উইজার্ডে দেশ **Bangladesh**, মুদ্রা **BDT (৳)** দিন। ACF বা অন্য কোনো পেইড প্লাগিন লাগবে না।

## ২. ডেমো/শুরুর ডেটা সিড করা (ঐচ্ছিক, প্রস্তাবিত)

ক্যাটাগরি, ১০টি পণ্য, হিরো/প্রোমো/ট্রাস্ট/ফুটার টেক্সট, মেনু, কুপন (`GOROM10` = ১০%, `GOROMDEAL` = ৳২০০) ও ডেলিভারি/জেলা সেটিংস ইমপোর্ট হয়। **নকল রেটিং/রিভিউ ইমপোর্ট হয় না।** কমান্ডটি আবার চালালেও ডুপ্লিকেট হয় না (SKU দিয়ে মেলানো হয়)।

- **অ্যাডমিন বাটন:** WP Admin → **Gorom Headless → ফ্রন্টএন্ড কানেকশন** → "ডেমো ডেটা ইমপোর্ট করুন"
- **WP-CLI:**
  ```bash
  wp gorom seed
  wp gorom seed --overwrite-settings   # আগে সেভ করা সেটিংস ওভাররাইট করতে
  ```
- প্রাইভেসি/রিটার্ন পলিসি পেজ **ড্রাফট** হিসেবে তৈরি হয়; আইনি লেখা আপনি নিজে লিখে পাবলিশ করুন।

## ৩. WooCommerce REST API কী (শুধু পড়ার)

1. **WooCommerce → Settings → Advanced → REST API → Add key**
2. Description: `Next.js frontend`, User: অ্যাডমিন, Permissions: **Read**
3. যে `Consumer key` (`ck_...`) ও `Consumer secret` (`cs_...`) পাবেন সেগুলো কপি করে রাখুন (একবারই দেখায়)।

## ৫. ফ্রন্টএন্ড — লোকাল রান

```bash
cd frontend
cp .env.example .env.local     # ভ্যালু বসান
npm install
npm run dev                    # http://localhost:3000
npm run build && npm start     # প্রোডাকশন বিল্ড
```

### Environment ভেরিয়েবল

| নাম | বিবরণ |
|---|---|
| `WC_URL` | WordPress সাইটের URL (যেমন `https://cms.goromdeal.com`) |
| `WC_KEY` / `WC_SECRET` | ধাপ ৩-এর Read-only কী (সার্ভার-সাইড) |
| `SITE_URL` | ফ্রন্টএন্ডের পাবলিক URL (sitemap/canonical) |
| `WP_IMAGE_HOSTS` | অতিরিক্ত ইমেজ হোস্ট (কমা দিয়ে); `WC_URL`-এর হোস্ট স্বয়ংক্রিয় |
| `WP_IMAGE_UNOPTIMIZED` | লোকাল WP (localhost/প্রাইভেট IP) হলে `1` |
| `REVALIDATE_SECRET` | লম্বা র‍্যান্ডম স্ট্রিং — ওয়েবহুকের সিক্রেট |
| `GD_PROXY_SECRET` | লম্বা র‍্যান্ডম স্ট্রিং — অর্ডারে আসল ক্লায়েন্ট IP পাঠানোর কী |

> `WC_URL` সেট না থাকলেও `npm run build` সফল হয় — তখন খালি অবস্থা (empty state) দেখায়, কোনো নকল ডেটা নয়।
> র‍্যান্ডম সিক্রেট বানাতে: `openssl rand -hex 32`

## ৬. Vercel-এ ডিপ্লয়

1. GitHub রিপো Vercel-এ Import করুন; **Root Directory = `frontend`**, Framework = Next.js।
2. **Settings → Environment Variables** এ উপরের সব ভেরিয়েবল দিন (Production + Preview)।
3. Deploy করুন; ডোমেইন সংযুক্ত করে `SITE_URL` আপডেট করুন।

## ৭. রিভ্যালিডেট ওয়েবহুক (কনটেন্ট বদলালে সাইট আপডেট)

পেজগুলো ISR (প্রতি ৫ মিনিটে রিফ্রেশ)। তাৎক্ষণিক আপডেটের জন্য:

WP Admin → **Gorom Headless → ফ্রন্টএন্ড কানেকশন**:
- ফ্রন্টএন্ড URL: `https://your-store.vercel.app`
- রিভ্যালিডেট URL: `https://your-store.vercel.app/api/revalidate`
- REVALIDATE_SECRET: Vercel env-এর মানটাই
- GD_PROXY_SECRET: Vercel env-এর মানটাই
- "ওয়েবহুক চালু" টিক দিন, সেভ করুন।

এরপর পণ্য/ক্যাটাগরি/মেনু/পেজ/সেটিংস সেভ করলে (ও স্টক বদলালে) প্লাগিন `POST /api/revalidate` পাঠায় (`{secret, tags, paths}`), ফলে শুধু সংশ্লিষ্ট পেজ নতুন হয়। টেস্ট:

```bash
curl -X POST https://your-store.vercel.app/api/revalidate \
  -H "Content-Type: application/json" \
  -d '{"secret":"<REVALIDATE_SECRET>","tags":["products"],"paths":["/"]}'
```

## ৮. অর্ডার ও ট্র্যাকিং

- চেকআউট → `POST /api/order` → প্লাগিন `gd/v1/order`: সার্ভারে দাম/ডেলিভারি/কুপন পুনর্গণনা, ফোন যাচাই (`^01[3-9]\d{8}$`), ফোন/IP রেট লিমিট, ডুপ্লিকেট চেক, হানিপট; তারপর WooCommerce অর্ডার (COD) তৈরি। WooCommerce → Orders এ দেখা যাবে।
- ট্র্যাক → `GET /api/track?order=&phone=` — অর্ডার নম্বর + ফোন মিললে স্ট্যাটাস ও অর্ডার নোট (customer note) দেখায়।

## ৯. সীমাবদ্ধতা / জানা বিষয়

- শুধু ক্যাশ অন ডেলিভারি (COD)। অনলাইন পেমেন্ট গেটওয়ে নেই।
- ভ্যারিয়েবল প্রোডাক্ট সাপোর্ট নেই; "অপশন" শুধু অর্ডার আইটেমে টেক্সট হিসেবে যায়। ট্যাক্স ধরা হয়নি।
- রিভিউ জমা দেওয়া ও নিউজলেটার সাবস্ক্রিপশন নেই। রেটিং শুধু WooCommerce-এ আসল রিভিউ থাকলে দেখায়।
- সার্চ সার্ভার-সাইডে সর্বোচ্চ ৩০০ পণ্যের মধ্যে খোঁজে।
- প্লাগিনটি আপনার WP-তে লাইভ চালিয়ে পরীক্ষা করা হয়নি (এই ডেভেলপমেন্ট পরিবেশে WP ছিল না) — প্রথমবার স্টেজিংয়ে চালিয়ে দেখে নিন।
